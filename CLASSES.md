# Классы лабораторной №4

| Класс | Назначение |
|---|---|
| `Main` | Демонстрирует все операции и три запроса SELECT. |
| `Department` | Сущность отдела со списком сотрудников и каскадным удалением. |
| `Developer` | Сущность сотрудника со связями с отделом и аккаунтом. |
| `UserAccount` | Учётная запись сотрудника с общим первичным ключом. |
| `UserRole` | Роли пользователя. |
| `HibernateUtil` | Создаёт SessionFactory и проводит операции в транзакциях. |
| `DepartmentDao` | Поиск, добавление, удаление отдела; выборка по месту. |
| `DeveloperDao` | Создание и перевод сотрудника; выборки по опыту и отделу. |
| `UserDao` | Создание аккаунта и поиск по username. |
