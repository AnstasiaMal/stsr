# Лабораторная работа №4 — JPA / Hibernate

Автор: Малюкевич А.С. Нужны JDK 21 и Maven 3.9+. Контейнеры, MySQL и внешние параметры не требуются: в проекте настроена файловая H2.

В каталоге репозитория выполните:

```powershell
mvn clean compile exec:java
```

При первом запуске Hibernate создаёт таблицы и исходные записи в `target/lr4-db.mv.db`. Программа показывает поиск отдела и пользователя, перевод сотрудника, три запроса `SELECT`, связи отделов с сотрудниками и каскадное удаление. Повторный запуск использует имеющуюся базу. Для чистого повторения удалите папку `target` или выполните `mvn clean compile exec:java`.

Классы перечислены в `CLASSES.md`; отчёт — в `report-lr4.docx`, его текст и рисунки — в `report-lr4.md` и `report-assets/`.
