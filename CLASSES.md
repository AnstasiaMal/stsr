# Классы лабораторной №3

| Класс | Назначение |
|---|---|
| `Main` | Запускает четыре части работы и принимает город и даты. |
| `WeatherRecord` | Хранит одно измерение погоды. |
| `WeatherSaxHandler` | Собирает измерения из событий SAX. |
| `SaxDemo` | Фильтрует измерения и вычисляет среднюю температуру. |
| `Employee` | Представляет сотрудника с новыми полями email и phone. |
| `DomDemo` | Создаёт, читает, ищет и удаляет сотрудников в XML. |
| `Department` | Модель подразделения для JAXB. |
| `Organization` | Корневой объект организации со списком подразделений. |
| `JaxbDemo` | Сохраняет и считывает организацию через JAXB. |
| `Lesson` | Модель занятия для JSON. |
| `GsonDemo` | Записывает и читает занятия через Gson. |
